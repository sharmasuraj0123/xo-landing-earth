Process

Create. Setup. Share.

01

Create a project

Pick a template: Cowork, OpenClaw, Hermes, or Claude Code. Your agent gets its own workspace, an ID, and a status the moment it exists.

xo.create({ template: 'claude-code', name: 'gcpt-e', }) // -> project f6cf3515 · Ready
02

Setup the checklist

Three steps to bring the agent online: connect a model, sync your data, add secrets. The checklist takes it from created to ready.

project.setup({ model: 'claude', data: ['knowledge/'], secrets: ['LINEAR_API_KEY'], })
03

Share and measure

Share the project with anyone by email. Then watch the work land: messages, sessions, cost, and latency, per project.

project.share({ with: 'bob@company.com' }) project.usage() // -> cost · tokens · messages · latency
